# Design Patterns — Senior Question List

Target level: **Senior Java Backend Developer**

This is an English-first root question file for the `java-interview-questions` repository.

The original PDF contains a compact Design Patterns block with questions about pattern definitions, categories, Singleton, thread-safe Singleton, double-checked locking, Factory Method vs Abstract Factory, Builder, Prototype, Strategy, Observer, Decorator, State vs Strategy, Proxy, Iterator and anti-patterns. This file keeps those questions translated to English and expands the topic to a senior-level Java backend interview checklist.

## Legend

- 🔥 **Bold questions** = Priority 1 / must know for the first pass.
- Regular questions = Priority 2 / recommended for deeper preparation.
- The list intentionally keeps several levels:
  - definition questions: “What is it?”
  - comparison questions: “How is it different from a similar pattern?”
  - implementation questions: “How would you implement it in Java/Spring?”
  - production questions: “What can go wrong?”
  - scenario questions: “Which pattern would you choose and why?”

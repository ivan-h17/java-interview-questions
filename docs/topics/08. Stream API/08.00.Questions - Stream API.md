# Stream API — Senior Question List

Target level: **Senior Java Backend Developer**

This is an English-first root question file for the `java-interview-questions` repository.

The original PDF block covers questions **318–346**: Stream API advantages, intermediate and terminal operations, `filter()`, `map()`, `collect()`, `Collector`, `flatMap()`, parallel streams, `ForkJoinPool`, external mutable state, side effects, `reduce()`, `peek()`, Stream reuse, lazy evaluation, `distinct()`, `sorted()`, `limit()`, `skip()`, short-circuiting, match operations, `findFirst()`, `findAny()`, collecting to `Map`, duplicate keys and `Optional` in streams.

This expanded checklist keeps the original topics and adds senior-level Java backend questions about Stream internals, pipeline lifecycle, collectors, reduction contracts, ordering, parallel execution, `Spliterator`, side effects, primitive streams, performance, resource boundaries, backend usage patterns, testing, modern Stream API additions and production troubleshooting.

## Legend

- 🔥 **Bold questions** = Priority 1 / must know for the first pass.
- Regular questions = Priority 2 / recommended for deeper preparation.
- The list intentionally keeps both levels:
  - definition questions: “What is it?”
  - deep-dive questions: “How does it work under the hood?”
  - production questions: “What can go wrong and how would you debug it?”

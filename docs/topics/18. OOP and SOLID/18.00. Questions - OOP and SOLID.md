# OOP and SOLID — Senior Question List

Target level: **Senior Java Backend Developer**

This is an English-first root question file for the `java-interview-questions` repository.

It translates and expands the original OOP / SOLID questions from the interview checklist into a senior-level Java backend preparation map.

## Legend

- 🔥 **Bold questions** = Priority 1 / must know for the first pass.
- Regular questions = Priority 2 / recommended for deeper preparation.
- The list intentionally keeps both levels:
  - definition questions: “What is it?”
  - deep-dive questions: “How does it work under the hood / in Java?”
  - production questions: “What can go wrong and how would you refactor/debug it?”

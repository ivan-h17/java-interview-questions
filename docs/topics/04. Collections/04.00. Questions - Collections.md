## Legend

- 🔥 **Bold questions** = Priority 1 / must know for the first pass.
- Regular questions = Priority 2 / recommended for deeper preparation.
- The list intentionally keeps both levels:
  - definition questions: “What is it?”
  - comparison questions: “How is it different from a similar concept?”
  - deep-dive questions: “How does it work under the hood?”
  - production questions: “What can go wrong and how would you debug or design around it?”

## Summary

- Total questions: **229**
- Priority 1 questions: **162**
- Priority 2 questions: **67**

This topic covers the Java Collections Framework as a senior Java backend topic: hierarchy, implementation trade-offs, time complexity, memory behavior, mutability, iteration rules, concurrent collections, API design and production pitfalls.

The goal is not only to know names like `ArrayList`, `HashSet` and `ConcurrentHashMap`, but also to explain when a collection is appropriate, how it behaves under the hood, what its concurrency guarantees are, and what can go wrong in a real service.

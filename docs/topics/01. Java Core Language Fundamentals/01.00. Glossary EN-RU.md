| fat / uber JAR | толстый / uber JAR | JAR that bundles application classes and dependencies together. |

| NoSuchMethodError | ошибка отсутствующего метода во время выполнения | Linkage error often caused by compiling against one dependency version and running with another. |

| numeric promotion | числовое продвижение (numeric promotion) | Rules that promote operands to a common numeric type before arithmetic. |
| widening conversion | расширяющее преобразование (widening conversion) | Implicit conversion to a type with a wider range according to Java conversion rules. |
| narrowing conversion | сужающее преобразование (narrowing conversion) | Conversion to a narrower type, usually requiring an explicit cast and possibly losing information. |
| integer overflow | переполнение целого числа | Wraparound when an integral arithmetic result does not fit the target primitive type. |
| checked arithmetic | проверяемая арифметика | Arithmetic that fails fast on overflow, for example Math.addExact. |
| floating-point | число с плавающей точкой | Approximate binary numeric representation used by float and double. |
| precision | точность (precision) | Number of significant digits represented or used in a numeric calculation. |
| rounding mode | режим округления | Rule used when an exact result cannot be represented at the requested scale or precision. |
| BigDecimal | BigDecimal | Immutable arbitrary-precision decimal number with explicit scale. |
| scale | масштаб (scale) | Number of digits to the right of the decimal point in a BigDecimal. |
| unscaled value | немасштабированное значение (unscaled value) | Integer component of a BigDecimal before applying scale. |
| NaN | NaN / не число | Special floating-point value representing an undefined or unrepresentable numeric result. |
| infinity | бесконечность (infinity) | Special floating-point value representing positive or negative overflow-like results. |
| signed zero | знаковый ноль (signed zero) | Floating-point distinction between +0.0 and -0.0. |
| UTF-16 code unit | кодовая единица UTF-16 | 16-bit unit used by Java char and String storage model. |
| Unicode code point | кодовая точка Unicode | Numeric value assigned to a Unicode character or symbol. |
| surrogate pair | суррогатная пара | Two UTF-16 code units representing one supplementary Unicode code point. |
| pass-by-value | передача по значению | Method-call rule where the argument value is copied into the parameter. |
| object reference | ссылка на объект | Value that identifies or points to an object; Java passes references by value. |
| defensive copy | защитная копия | Copy made to avoid sharing mutable internal state with callers. |
| array covariance | ковариантность массивов | Rule that allows Subtype[] to be assigned to Supertype[], with runtime store checks. |
| reified type | тип, сохранённый во время выполнения (reified type) | Type information preserved at runtime, as with array component types. |

| upcasting | восходящее приведение (upcasting) | Conversion from subtype reference to supertype reference. |
| downcasting | нисходящее приведение (downcasting) | Runtime-checked conversion from supertype reference to subtype reference. |
| ClassCastException | ClassCastException | Runtime exception thrown when an object is cast to an incompatible type. |
| overload resolution | разрешение перегрузки | Compile-time process that selects the applicable method signature for an overloaded call. |
| most specific method | наиболее специфичный метод | The best applicable overload according to Java specificity rules. |
| fixed arity | фиксированное число аргументов | Method invocation form that does not use varargs expansion. |
| variable arity | переменное число аргументов | Method invocation form that uses a varargs parameter as an array. |
| compile-time type | статический тип / compile-time type | Type known to the compiler at a call site. |
| runtime type | фактический тип во время выполнения (runtime type) | Actual class of an object during execution. |
| method overloading | перегрузка методов | Multiple methods with the same name but different parameter lists. |
| method overriding | переопределение методов | Subclass implementation of an inherited instance method signature. |
| static dispatch | статическая диспетчеризация | Selection determined at compile time, as with overload signature choice. |
| dynamic dispatch | динамическая диспетчеризация | Runtime selection of an overridden instance-method implementation by receiver type. |

| logical equality | логическое равенство | Domain-level equality implemented by equals according to class-specific rules. |
| equivalence relation | отношение эквивалентности | Relation that is reflexive, symmetric, transitive and consistent for equality purposes. |
| identity equality | равенство по идентичности | Equality where only references to the same object are considered equal. |

| equals/hashCode contract | контракт equals/hashCode | Rule that equal objects must have equal hash codes and equality must remain consistent. |

| NullPointerException | NullPointerException | Runtime exception thrown when code tries to use null as an object. |
| Optional | Optional | Container type commonly used to represent expected absence of one return value. |
| Null Object pattern | паттерн Null Object | Pattern that uses a harmless object with default behavior instead of null. |
| getClass() | getClass() | Object method that returns the runtime Class of an object. |
| instanceof | instanceof | Operator that tests whether a reference is an instance of a type. |
| canEqual pattern | паттерн canEqual | Equality pattern used to preserve contracts in extensible class hierarchies. |
| Object | Object | Root class of the Java class hierarchy. |
